## 🎯 ما هو NexFlow System؟

نظام إدارة أعمال احترافي يجمع بين:
- **نقاط البيع (POS)** — بيع سريع بالباركود، سلة ذكية، طباعة إيصال
- **إدارة المخزون** — منتجات، فئات، حركات مخزون، تسويات
- **المحاسبة** — مصروفات، تقارير، سجل عمليات، خزنة
- **إدارة العملاء** — CRM، نقاط ولاء، فئات VIP

يعمل **100% offline** — كل البيانات محلية في SQLite. لا حاجة لإنترنت أو Supabase.

## 📁 تنظيم الوحدات

الشريط الجانبي مقسّم لـ 5 أقسام منطقية:

### 🔹 العمليات (Operations)
- لوحة التحكم · نقطة البيع · المبيعات · الخزنة

### 🔹 المخزون (Inventory)
- المنتجات · الفئات · المخزون · المشتريات · الموردون

### 🔹 العملاء (CRM)
- العملاء · نقاط الولاء

### 🔹 المحاسبة (Accounting)
- المصروفات · التقارير · سجل العمليات

### 🔹 النظام (System)
- الموظفون · الأوفلين · تحميل البرنامج · الإعدادات

## 🚀 التشغيل

### المتطلبات
- **Rust** + **Node.js 18+**
- Windows: C++ Build Tools + WebView2
- macOS: Xcode CLI
- Linux: webkit2gtk dev libs

### التثبيت والتشغيل

```bash
git clone https://github.com/mathatqra-arch/beauty-pos-offline.git
cd beauty-pos-offline
npm install
npm run tauri:dev      # وضع التطوير
# أو
npm run tauri:build    # نسخة production (installer)
```
